# AnchorCounter
AnchorCounter A Fabric mod for Minecraft 1.21 that tracks Respawn Anchor placements and explosions for all nearby players.

## Features

- Track anchor placements and explosions for all players
- Customizable display format
- HUD overlay with real-time statistics
- ModMenu integration for easy configuration
- Keybindings for quick access
- Client-side only

## Usage

### Commands

| Command | Description |
|---------|-------------|
| `/showexplodeds` | Show statistics for all tracked players |
| `/resetanchors` | Reset all anchor statistics |
| `/resetanchors <player>` | Reset statistics for specific player |
| `/anchorcounter toggle` | Toggle HUD display on/off |
| `/anchorcounter reload` | Reload configuration from file |
| `/anchorcounter help` | Show help message |
| `/ac` | Alias for `/anchorcounter` |


### Keybindings

All keybindings can be changed in `Options > Controls > AnchorCounter`

| Key | Action |
|-----|--------|
| `]` | Toggle display on/off |
| `\` | Reset all statistics |
| `=` | Reload configuration |
| `-` | Show statistics in chat |
